# GRIYA NUSA - Template Landing page Gratis

Template landing page GRIYA NUSA gratis untuk pengelolaan properti, berbasis Laravel 13 + Inertia.js + React + Tailwind. Download ZIP full project di TemplatKu.

Template ini adalah bagian dari galeri TemplatKu: 60 template dashboard dan landing page gratis berbasis Laravel 13 + Inertia.js + React + Tailwind CSS, siap download sebagai ZIP full project Laravel.

- Demo template: http://95.111.197.157/templates/landing-properti
- Galeri lengkap: http://95.111.197.157/

## Cara install

```bash
# 1. Extract ZIP hasil download, lalu masuk ke foldernya
composer install
cp .env.example .env
php artisan key:generate
npm install && npm run build
php artisan serve
```
